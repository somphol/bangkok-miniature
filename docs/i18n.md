# Internationalization

The interface ships in **English** and **Thai**. The scene itself has no text; the copy lives in
`src/i18n.ts` and the language is selected by `?lang=` or the `ไทย` / `EN` button.

## How it works

- `STRINGS` is a nested object with an `en` and a `th` block. The `Strings` type is derived from the
  English block, so a missing key is a TypeScript error.
- `normaliseLang()` maps `th`, `thai`, `th-*` to `th`; everything else is `en`.
- `?lang=th` sets the initial language. The button switches live and tries to update the URL; in a
  sandboxed document (opaque origin) the URL update is skipped, but the UI still switches.
- `document.documentElement.lang` and `document.title` are updated on every language change.
- Landmark copy uses a fixed key order: `LANDMARK_KEYS` maps the eight landmarks to
  `lmGrandPalace…`, `lmWatArun…`, `lmWatPho…`, `lmGiantSwing…`, `lmGoldenMount…`, `lmBaiyoke…`,
  `lmMahanakhon…`, `lmRamaViii…`. Each has `Name`, `Area`, `Text` and `Short`.
- The full landmark bar uses `Short`; the info card uses `Name`, `Area` and `Text`.

## Adding a locale

1. Copy the `en` block in `src/i18n.ts` and translate every value.
2. Add the new block to `STRINGS`.
3. Add the language to `LANGS` and `normaliseLang`.
4. Add a locale check to `scripts/verify.mjs` (title and landmark label are enough).
5. Update the README/getting-started language table.
6. Check the compact bar: the `Short` labels are the tightest fit. A 4×2 grid at 345 px gives each
   button about 78 px.
7. Check the info card and the intro at 900–1200 px; some languages run longer than English.

## Copy guidelines

- Keep UI labels short: `Day`, `Night`, `Reset view`, `Auto rotate`.
- The title is editorial, not a translation of a product name: English “Bangkok in miniature.”,
  Thai “กรุงเทพฯ ในแบบจำลอง”.
- Use sentence case for body copy and uppercase only for the small tracked labels.
- Do not translate the landmark names into a different landmark; use the accepted local name (for
  example `พระบรมมหาราชวัง`, `วัดอรุณ`, `วัดโพธิ์`, `เสาชิงช้า`, `ภูเขาทอง`, `ใบยอกทาวเวอร์ 2`,
  `คิงพาวเวอร์มหานคร`, `สะพานพระราม 8`).
- Keep the coordinates and the volume line (`VOL. 002`) in Latin numerals; they are part of the
  collectible design.

## Thai typography

- Thai has no spaces between words in the same phrase; the browser's line breaker handles it, but
  the info card is narrow, so test long landmark descriptions.
- The UI uses system fonts. macOS has Thonburi/Ayuthaya; some Linux images do not. The CSS falls
  back through `"Thonburi", "Noto Sans Thai", sans-serif` for the UI and the serif stack for the
  title.
- The Thai title uses the same serif stack as English; if the system lacks a Thai serif, it falls
  back to the sans face. That is acceptable; do not ship a font file (the single file must stay
  offline and font-free).
- Set `lang="th"` on the document (the app does) so screen readers and line breaking use Thai rules.

## Accessibility

- Every icon-only control has an `aria-label` and, where it is a toggle, `aria-pressed`.
- The landmark buttons expose the full name on compact layouts via `aria-label`; the visible label
  is the short name.
- The language button's label is the *other* language (`ไทย` in English, `EN` in Thai).
- The scene container has an `aria-label` describing the 3D miniature.
- The snapshot dialog has `role="dialog"`, `aria-modal="true"` and a labelled close button.
- The colour palette is checked for the day and night panels; the gold-on-ink and cream-on-ink
  combinations are the primary contrast pairs.
